    Retraining (command line)

    Training runs from the command line so it can be reproduced and reviewed. It uses only labelled real readings and refuses to train when classes or sessions are insufficient:

    train.bat                 (Windows)      ./train.sh                (Linux)
train.bat synthetic       demonstration model from synthetic data
python -m ml.registry list | activate <version> | rollback

    Then press Reload model from registry above (admin token required) or restart the backend.
